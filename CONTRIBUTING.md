# Як долучитися до проєкту (Contributing Guidelines)

Дякуємо за ваш інтерес до покращення української локалізації **ExpressionEngine 7**! Будь-який внесок — виправлення одруківки, покращення термінології чи оновлення для нових версій EE — дуже вітається.

---

## 📋 Основні правила внесення змін

1. **Створення гілки (Branching):**
   - Форкніть репозиторій.
   - Створіть нову тематичну гілку: `git checkout -b fix/typo-in-channel-lang` або `git checkout -b feature/update-ee76`.
2. **Формат файлів:**
   - Кодування обов'язково **UTF-8 без BOM**.
   - Перенесення рядків — **LF (Unix)**.
   - Зберігайте синтаксис асоціативних масивів PHP (`'key' => 'значення',`).
3. **Збереження змінних та плейсхолдерів:**
   - **Не перекладайте та не видаляйте** спеціальні змінні: `%s`, `%d`, `%x`, `{elapsed_time}`, `{name}`, `{site_name}` тощо.
   - Зберігайте HTML-теги у рядках (наприклад `<abbr>`, `<strong>`, `<a>`).
4. **Створення Pull Request:**
   - Давайте зрозумілі назви комітам (наприклад, `fix: correct pluralization in members_lang.php`).
   - Опишіть суть змін у PR.

---

## 📖 Глосарій термінів ExpressionEngine

Для збереження єдності термінології в усій панелі керування дотримуйтесь наступного глосарію:

| Термін англійською | Український переклад | Примітки / Контекст |
|---|---|---|
| **Add-on** | Додаток | Розширення можливостей EE |
| **Channel** | Канал | Основна сутність для структури контенту |
| **Channel Entry / Entry** | Запис каналу / Запис | Окремий матеріал або публікація |
| **Channel Field** | Поле каналу | Поле форми введення контенту |
| **Category / Category Group** | Категорія / Група категорій | Класифікація записів |
| **Comment** | Коментар | Коментарі користувачів |
| **Control Panel (CP)** | Панель керування | Адміністративний інтерфейс |
| **Fieldtype** | Тип поля | Механізм введення даних (текст, дата, тощо) |
| **Fluid Field** | Гнучке поле | Спеціальний тип поля EE |
| **Member** | Учасник | Зареєстрований користувач сайту |
| **Member Role / Role** | Роль учасника / Роль | Права доступу (раніше Member Group) |
| **Member Group (Legacy)** | Група учасників | Для сумісності з попередніми версіями |
| **Module** | Модуль | Системний модуль EE |
| **Plugin** | Плагін | Плагін обробки шаблонів |
| **Relationship** | Зв'язок | Зв'язок між записами каналів |
| **Site** | Сайт | У контексті Multi-Site Manager (MSM) |
| **Snippet** | Сніпет | Фрагмент шаблону |
| **Super Admin** | Супер Адміністратор | Роль з максимальними правами |
| **Template** | Шаблон | Шаблон відображення сторінок |
| **Template Group** | Група шаблонів | Тека/група шаблонів |
| **Upload Destination** | Місце завантаження | Каталог для збереження завантажених файлів |

## ✍️ Стилістика та правила перекладу

- **Звернення до користувача:** Вживайте ввічливе звернення на «ви» з маленької літери в інтерфейсних текстах та повідомленнях («Виберіть файл», «Ваш профіль оновлено»).
- **Лапки:** В інтерфейсі використовуйте звичайні апострофи з екрануванням для PHP (`\'`) та лапки-ялинки «...» або стандартні подвійні лапки там, де це доречно.
- **Дієслова у формах та кнопках:** Називайте дії інфінітивом або наказовим способом («Зберегти», «Видалити», «Оновити», «Переглянути»).
